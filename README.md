#### Frågeställningar
- Git add är när du förbereder ändringar du gjort innan du faktiskt sparar dina ändringar
- Git commit är när du sparar ändringar som en punkt i din historik lokalt på datorn och du skriver ett meddelande om vad du gjort.

- Vi använder branches för att inte påverka vår main fil som faktiskt fungerar, så ifall vi vill bygga en till modul och testa den så vi inte pajjar det vi redan byggt så skapar vi en branch och sen om allt funkar kan vi merga ihop dom i main

- När vi mergar så trycker vi in den koden vi skrev vid sidan av (branch) och för in den i main och gör projektet komplett. Så om vi har en hemsida som är live så kan man numera använda den funktionen vi byggde i en branch!

- Skillnaden på git och netlify borde vara att på git sparar den all info och jag kan enkelt arbeta med det och smidigt pusha upp nu ändringar och den sköter sen allt åt mig när det kommer till att hantera filer och versioner. Medans i netlify måste jag ju själv gå in varje gång jag ändrat koden och lägga upp dom nya filerna och då sparas ju inte mina olika versioner där.

- Då gör man en .gitignore fil och i den filen skriver man sen namnet på filen man vill exkludera. Filen finns fortfarande lokalt på min dator men det åker inte med till github ifall man vill spara nån känslig information.
